# Control Systems to Robotics

An interactive educational webpage bridging classical control theory to modern robotics and Vision-Language-Action (VLA) systems.

## 🌐 Live Demo

[**Open Interactive Page**](https://raj-abhishek-barad.github.io/Control-Systems-to-Robotics/Downloads/control_freq_domain.html)

## 📖 Topics Covered

- **Time-Domain Analysis** — step response, damping ratio, overshoot, rise time, settling time
- **Frequency-Domain Analysis** — Bode magnitude and phase plots, bandwidth, roll-off
- **Stability Margins** — gain margin, phase margin, instability boundary
- **Examples**
  - RC circuit (low-pass filter interpretation)
  - Mass-spring-damper (mechanical resonance)
  - Robot joint control (closed-loop feedback)
- **Modern Robotics & VLA Systems** — connecting classical control to neural robot policies, inference delay, actuation bandwidth

## 🎛️ Interactive Elements

- Step response plot with live ζ and ω_n sliders
- Bode magnitude + phase plot with resonance peak visualization
- Mass-spring-damper frequency response with resonance zone highlighting

## 🚀 Usage

No installation needed. Either:
